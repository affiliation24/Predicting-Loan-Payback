# Предсказание возврата кредита

## Описание

Задача бинарной классификации: предсказать, вернёт ли заёмщик кредит (`loan_paid_back`). Модель обучается на ~594 000 кредитных записях с использованием градиентного бустинга и кросс-валидации. Цель — точно оценить риск дефолта на основе финансовых и демографических признаков.

## Пайплайн

### 1. Загрузка и первичный анализ данных
- Загрузка `train.csv` и `test.csv` через `pandas`
- Анализ типов данных, пропусков, уникальных значений
- Описательная статистика (`describe()`)

### 2. Разведочный анализ данных (EDA)
- Тепловая карта корреляций числовых признаков
- Распределение целей займа (`loan_purpose`)
- Автоматический HTML-отчёт через `ydata_profiling` → `loan_report.html`

### 3. Предобработка признаков
- Разделение признаков на числовые и категориальные
- `grade_subgrade` выделен как порядковый (отдельно от номинальных)
- `ColumnTransformer`:
  - **Числовые** → `RobustScaler` (устойчив к выбросам)
  - **Номинальные категориальные** → `OneHotEncoder` (неизвестные значения игнорируются)
  - **Порядковые категориальные** → `OrdinalEncoder` (неизвестные → `-1`)

### 4. Обучение модели с кросс-валидацией
- Стратегия: `StratifiedKFold` (5 фолдов, shuffle=True, random_state=42)
- Модель: `XGBClassifier` в `sklearn Pipeline`
- Гиперпараметры:
  ```
  n_estimators  = 2000
  learning_rate = 0.05
  max_depth     = 6
  eval_metric   = 'auc'
  ```
- Предсказания на тесте усредняются по фолдам

### 5. Оценка модели
- Метрики на отложенной выборке (разбивка 80/20): Accuracy, ROC AUC, Classification Report
- Построение ROC-кривой
- График топ-20 важности признаков (XGBoost feature importances)

## Запуск

### 1. Установка зависимостей

```bash
pip install pandas numpy matplotlib seaborn scikit-learn xgboost ydata-profiling
```

### 2. Подготовка данных

Файлы датасета должны находиться в папке `data/`:

```
data/
├── sample_submission.csv
├── test.csv
└── train.csv
```

### 3. Запуск ноутбука

```bash
jupyter notebook train.ipynb
```

Или запуск всех ячеек без интерфейса:

```bash
jupyter nbconvert --to notebook --execute train.ipynb --output train_executed.ipynb
```

> **Python версия:** 3.11.3 (`.venv`)
